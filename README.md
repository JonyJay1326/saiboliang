# 赛博粮站 · saiboliang

> 大厂开仓，凭票领饭。

日更型 AI「白嫖机会 + 比价 + 榜单」聚合站：把散落在厂商官网、榜单和公告里的免费额度、活动、模型强弱与价钱、编程订阅套餐，整理成一张张可核验的古风票证，每天自动开仓三次。

- 线上站点：<https://saiboliang.top>
- 形态：纯静态站点（Astro + Vue 岛），无后端、无登录、无用户数据
- 节奏：每天 3 次自动采集 → 校验 → 构建 → 部署（北京时间 11:17 / 15:17 / 19:17 前后）

## 功能概览

全站导航遵循「**板块名 · 动作**」格式：一眼看清来这里能干什么。

| 板块（导航名） | 路由 | 功能 |
| --- | --- | --- |
| **太仓 · 首** | `/` | 全站总览：今日份票卡 + 观星台 / 点将台摘要 |
| **粮票 · 领** | `/tickets`、`/tickets/[id]` | 免费额度与限时活动；一张票一个独立详情页，可筛选、可排序 |
| **观星台 · 望** | `/github` | GitHub Trending 周 / 月榜中的 AI 项目精选，附中文简介 |
| **点将台 · 比** | `/models` | Artificial Analysis 综合榜与编程榜，附公开市场参考价 |
| **粮市 · 买** | `/plans`、`/plans/[id]` | 国内外编程订阅套餐同口径比价，编辑推荐序 |
| **邸报 · 看** | `/news` | AI 中文资讯精选：按北京日分栏，标题直达原文，附来源摘要 |
| 关于 | `/about` | 数据来源、更新节奏、推广披露与免责 |

几条贯穿全站的产品纪律：

- **票证上架有门槛**：推荐等级低于丙等的票与已失效票全站下架——列表不渲染、详情页不生成、不进 `sitemap.xml`，不会出现「搜索点得进、列表看不到」的鬼页。
- **筛选条件进 URL**：`/tickets` 的分类 / 地区 / 时长 / 本周新增筛选都写进 query，可分享、可回退。
- **弹框只是渐进增强**：列表页点标题可弹框预览详情；真链接照旧，爬虫可抓、无 JS 正常跳转、直接访问 URL 仍是独立详情页。
- **数据新鲜度常驻**：页头与页脚显示最后核验时间；采集失败时保留上次数据并标旧时间，不用模块时间掩盖条目年龄。

## 创意概览

### 一套隐喻，一条人格

站点是一间「粮站」：免费额度是**粮**，领取凭证是**票**，首页是**太仓**（全站总仓），厂商放出活动叫**开仓**，去过期叫**作废**。全站文案、装饰都在这一套名词体系内找得出处，不混搭体系外的新比喻。

### 气质：老机构 + 未来系统

四个关键词：**可信 · 古意 · 批号感 · 未来感**。

- **可信**是一票否决项——用户在这里做领取 / 付费决策，站面必须像一家有底账的老机构，而不是营销页。
- **古意**来自票证本身：票号、等级章、期限、骑缝，要素齐全，不做旧滤镜。
- **批号感**来自等宽字体的编号、时间戳与系统状态语。
- **未来感**是叠加层：光效、发光等宽数字、系统状态语，是「有后台系统的老机构」，不是未来主题乐园。

提供**朴素 / 赛博**两档皮肤，只切换装饰强度，不改结构、字段与文案；默认朴素档。

### 票证是真的

票卡是一张竖版票面：四角角标与内框、左侧竖排等级、中央朱红等级章、票面要素、票号与领取键。等级分**甲 / 乙 / 丙**三档，整卡随档换色；章只承担「等级」与「失效」两种语义，一章一义。

票证详情页是 SEO 主战场：真 URL + 构建期 SSG + `sitemap.xml` + JSON-LD（`Offer`），并公开「首次收录 / 最后编辑 / 推荐等级」——把信息的可靠过程本身做成可信度设计。

### 标题图片化（字体授权决定的技术路线）

站名、板块名、印章等固定文案标题，全部使用四款已获授权的书法字体**预渲染成 PNG** 上线：真实 `width`/`height`、防 CLS 配对、PNG8 量化。授权不含 webfont（子集化也不行），因此**禁止 `@font-face` 挂中文字库**；字体文件与授权证书不进本仓库。正文一律走系统字体栈。

### 透明与克制

- 站内推广链接显式标注「含推广」，推广与否不影响排序；`/about` 有常驻披露页。
- 只存「标题 + 简介 + 链接 + 事实数据」，**不存正文**——简介为来源自带，或由模型读取来源页面片段起草（正文不落盘）。是索引，不是转载。
- 板块延期时给的是施工占位页与旁路入口，不是 404、不是空列表。

## 数据从哪来

| 模块 | 来源 |
| --- | --- |
| 观星台 | GitHub Trending 官方周 / 月榜（全局 + 语言榜），剔除付费赞助位后按 AI 主题筛选 |
| 点将台 | Artificial Analysis 开放接口：综合 / 编程两榜，报价用其自带定价 |
| 粮市 | 厂商官方套餐页 / 文档，逐源适配器 + 人工校对，同币种同周期才比较 |
| 粮票 | 人工维护（`editorial/tickets.json`）：官方活动页为事实依据，管道只校验与打版本戳 |
| 邸报 | 厂商官方一手 RSS / 公告 / sitemap + AIBase / 量子位二手兜底；英文条目机译，简介来源自带或模型起草 |

公开数据为**五文件完整批次**（`version.json` / `tickets.json` / `models.json` / `github.json` / `news.json`）：构建期注入 JSON 保障 SEO，运行时比对 `version.json` 保持实时性——浏览器取到同批文件后才一次性替换。

## 工程与可靠性

- **采集管道**：Python 3.11+ 仅标准库，只产 JSON、不起服务。逐源失败隔离，来源异常时保留整个模块的旧数据与旧核验时间；关键源有骤降保护。
- **构建门禁**：采集→校验→构建在同一批次内进行，构建失败不推进 `public/data` 与每日成功状态，部署失败则跳过数据回写。
- **部署**：GitHub Actions 单 workflow 完成采集 + 构建 + 部署 + 数据回写；GitHub Pages 源站 + Cloudflare DNS/CDN。
- **性能预算**：无岛页首屏 JS < 15 KB（gzip）、有岛页 < 50 KB；列表类页面「岛只做列表控制器」，卡片构建期静态渲染，数据只出现一份。

## 本地运行

```powershell
# 后端：单测 / 采集 / 校验（Python 3.11+）
python -m unittest discover -s code-backend -v
python code-backend/pipeline.py collect --modules github news
python code-backend/pipeline.py validate

# 前端：开发 / 构建（Node 22）
cd code-frontend
npm ci
npm run dev
npm run build
```

环境变量见 `code-backend/.env.example`（`AA_API_KEY`、`DEEPSEEK_API_KEY`），Key 只存本机 `.env` 或 Actions Secret，绝不入库。

## 边界与延期项

- 数据字段以冻结的数据契约为唯一接缝，字段名与语义不得擅自变更。
- 一期不实现：票证五维评分与权重滑块、评分档位；GitHub 监控池与 star 差分历史。
- 版权红线：只存标题 + 简介 + 链接 + 事实数据，不存正文；收到权利人通知即删（下架入口二期补上）。

## 授权与隐私

- 站内使用的四款书法字体为用户持有的**个人商用授权**，仅通过预渲染图片产物对外呈现；字体文件与含个人信息的授权证书一律留本机，不进公开仓库。
- 仓库公开部分仅含站点代码、采集管道与人工维护数据；`.gitignore` 为白名单式，字体、证书、本地工具产物与凭据从机制上出不了仓库。
